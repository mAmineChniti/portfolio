# Med Amine Chniti — Portfolio

A personal engineering portfolio built with Next.js 16, React 19, TypeScript, Tailwind CSS 4, and Bun.

## Local development

```bash
bun install
bun run dev
```

Open `http://localhost:3000`.

## Verification

```bash
bun run typecheck
bun run lint
bun run format:check
bun run build
```

## Content

Portfolio content lives in `lib/projects.ts`, `lib/contributions.ts`, and `lib/stack.ts`. Project claims should be updated only when they can be verified against a repository, deployment, package registry, or merged contribution.

The production canonical URL is `https://maminechniti.dev`.
